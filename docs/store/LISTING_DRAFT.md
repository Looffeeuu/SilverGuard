## 详细描述

保健品“七天降血糖”、理疗仪“根治颈椎病”、理财“保本高收益”……这些话术经常让老人一时心动。银龄安心查帮你在付款前多核验一次。

**怎么用**
- 拍下商品包装，或选一张商品截图，手机会在本地识别文字
- 也可以直接粘贴淘宝、天猫商品链接，或手动输入宣传语

**能帮你看什么**
- 宣传风险：识别“包治”“不用吃药”“零风险”“仅限今天”等常见风险话术，并逐条说明为什么要警惕
- 登记信息：识别医疗器械、药品、保健食品、化妆品的注册或备案编号，提示宣传内容是否超出登记用途
- 官方核对：给出国家药监局、市场监管总局等官方查询入口，帮你记录核对结果
- 拿不准时：一键拨打家人电话、12315 消费投诉、96110 反诈咨询；已经付款的，提醒拨打 110

**为老人设计**
- 大字、高对比模式，按钮足够大
- 一键朗读分析结果
- 一键把结果发给子女一起看

**隐私**
- 不用注册账号，不申请相机、相册、通讯录、位置权限
- 照片在手机上识别，不上传；历史记录只存在手机里，可以随时删除
- 无广告

**请注意**
分析结果是消费风险辅助判断，不代表行政认定、医学诊断或官方认证，也不能证明商品是真是假。“没查到”不等于假货，“话术相似”也不代表商家就是骗子。买药、停药请遵医嘱。

## 上架前还缺什么

2. **开发者信息**：填写隐私政策里的开发者名称、联系邮箱、生效日期、答复时限。
3. **隐私政策网址**：应用商店通常要求提供一个可访问的网页地址，例如放在 GitHub Pages 或个人网站上。
4. ~~App 内展示隐私政策~~：已实现。首次启动先显示同意页，可查看完整政策；首页底部“隐私政策”可随时查看并撤回同意；政策内容一变会要求重新同意。
5. **国内商店资质**：部分商店对个人开发者或健康类 App 有额外要求，例如软件著作权、免责声明，请以各商店当前审核要求为准。
6. **版本号**：目前仍是 0.5.0，`main` 上的改动见 [版本历程](../RELEASE_NOTES.md)，发布前确定新版本号。
