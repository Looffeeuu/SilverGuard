# SilverGuard 版本历程

## 未发布（main 分支）

**风险规则**

- 识别否定句、法定警示语（如“保健食品不是药物，不能代替药物治疗疾病”）、合规风险揭示（“不保本”）和用户粘贴的防骗提示，不再误报。
- 识别到药品批准文号或医疗器械注册号时，说明书里的适应症用语不计分；“根治”“治愈”等承诺仍然计分。
- 非药品宣称治病时直接判为高风险，与“宣传内容与登记类型冲突”提示保持一致。
- 同一条规则命中多个不同说法时累加分数，投资骗局话术可以达到高风险。
- 统一治病、替代药物话术词表，并补充常见换说法（治好、降三高、停了降压药、到期还本、拉人头等）。
- 新增 75 条样本的风险规则评测集和基线：等级一致从 34/60 提升到 73/75，误报从 12 条降到 0 条。

**使用体验**

- 转屏、切换深色模式或调整系统字体时，分析结果、未提交的文字和正在进行的识别不再丢失。
- 拍照或打开官方网页期间应用被系统回收时，回来后恢复当前分析；补拍的照片仍合并到原商品。
- 中高风险结果新增求助卡片：一键拨打家人电话、12315、96110 和 110，只打开拨号界面，不自动拨出。家人电话只保存在本机。

**工程与发布**

- 页面状态迁移到 ViewModel，`SilverGuardApp.kt` 从 1387 行缩减到约 930 行。
- Release 构建开启 R8 代码压缩（APK 58 MB → 45 MB），签名信息从本机配置读取；修复 R8 导致 release 包 OCR 失效的问题；CI 同时构建 release 包。
- 当前验收：156 项 JVM 单元测试、11 项 Android UI 测试通过。

## v0.5.0 · 本地价格参考、案例提示与历史记录

- 暂停默认 AI 云调用，发布构建不携带代理配置。
- 增加用户录入的同款报价区间比较，不影响真假判断和原风险分数。
- 内置带公开监管来源的案例摘要与消费提示，本地匹配相似话术。
- 增加本机历史记录：最多 50 条，支持搜索、打开、删除和清空。
- 增加固定的返回首页 / 历史入口，并改善普通模式的颜色对比度。
- 结果详情保持折叠，底部家人分享按钮不再遮挡正文。
- 当前验收：123 项 JVM 单元测试、7 项 Android UI 测试通过。

## v0.4.0 · AI 语义分析实验

- 完成可选 AI Provider、隐私同意、文本脱敏、结构化响应与失败降级代码。
- 本地规则仍是风险分数的唯一来源，AI 不判断真假或替代官方核验。
- 因免费云服务延迟和稳定性不足，v0.5.0 默认关闭这项能力。

## v0.3.6 · 多来源综合输入

- 结果页持续保留文字输入、拍照与截图入口。
- 不同输入合并为同一份分析材料，不再互相覆盖。
- 结果页只先展示结论、行动和补充建议，详细证据按需展开。

## v0.3.5 · 老人可用性优化

- 首页收敛为拍照、截图、文字 / 链接三个大入口。
- 增加大字、高对比、中文朗读、TalkBack 语义和更大的触控目标。
- 信息不足时提醒准确性下降，补拍始终是建议而非强制。

## v0.3.4 · 官方截图辅助核对

- 使用设备端 OCR 识别官方查询截图。
- 对注册号、产品名、企业、型号规格与状态做谨慎比对。
- 将自动截图提示与用户人工确认明确分开。

## v0.3.3 · 官方人工核验记录

- 区分主要核验入口和辅助核对入口。
- 生成逐项核验清单并记录找到、未找到、页面异常和字段一致性。
- 分享报告携带来源、时间与人工记录。

## v0.3.2 · 淘宝 / 天猫公开页面解析

- 在 HTTPS 白名单和有限重定向范围内读取无需登录的公开信息。
- 优先解析 JSON-LD、Open Graph、Meta 和页面标题。
- 登录、验证码、403、超时或解析失败时正常降级为截图 / 手动输入。

## v0.3.1 · 电商链接识别

- 识别淘宝、天猫、拼多多、京东和抖音官方域名。
- 提取常见商品 ID、清理追踪参数，并拒绝相似钓鱼域名。

## v0.3.0 · 官方信息核验 MVP

- 分类医疗器械、药品、保健食品和化妆品常见编号。
- 增加核验准备度、官方来源、核验清单和宣传冲突提示。
- 明确不伪装成已经自动查询国家数据库。

## v0.2.2 · 商品信息结构化提取

- 从 OCR / 文字整理商品名、品牌、生产企业、型号、规格、编号和价格。
- 分享报告同步携带结构化字段。

## v0.2.1 · 交互与老人友好基础

- 原生 Kotlin + Jetpack Compose Android 应用。
- 支持拍照、系统相册、设备端中文 OCR、本地风险分与家人分享。
- 优化键盘、系统栏、结果解释和主要操作路径。
