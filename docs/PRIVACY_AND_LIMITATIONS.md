# 隐私与能力边界

SilverGuard 的可信度来自明确说明“做了什么”和“没有做什么”。本页描述 v0.5.0 的实际行为。

## 默认在设备端完成

- 中文 OCR 与截图文字识别
- 商品信息结构化提取
- 本地风险规则与宣传冲突分析
- 注册 / 备案编号格式分类
- 案例话术匹配与用户报价比较
- 分享文本和中文朗读内容生成
- 最近 50 条分析历史的保存与搜索

历史存放在应用私有、排除 Android 云备份和设备迁移的文件中。它包含用户输入文字、商品链接、结构化结果、人工核对和报价，但不保存原照片。用户可以删除单条或清空全部；卸载应用会删除历史。

## 可能发生的外部访问

- 用户分析受支持的淘宝 / 天猫链接时，App 可能读取无需登录即可访问的公开 HTML。
- 用户点击官方核验入口、案例来源或商品页面时，由系统浏览器或对应平台 App 打开。
- 打开一条本机历史记录本身不会重新联网；用户主动点击重新分析后才可能再次访问商品链接。

电商请求不携带淘宝账号、Cookie 或登录 token，不尝试绕过验证码、登录墙或平台限制。

## AI 状态

v0.5.0 默认设置 `SILVERGUARD_AI_ENABLED=false`：AI 入口隐藏，现有代理地址和令牌不会编入 APK，也不会产生云端请求或 Token 费用。

仓库保留实验性 AI Provider 与代理示例，方便未来继续开发。重新启用前仍需完成成本控制、隐私政策、数据处理说明、服务稳定性和用户同意流程。

## 不代表什么

SilverGuard 的结果不代表：

- 行政认定或官方认证
- 医学诊断、治疗建议或药品替代建议
- 对商品真伪、合法性、品质或功效的最终结论
- 实时、完整的市场价格或全网最低价
- 对某个品牌、店铺或销售人员的定性

“未找到”“信息不足”“缺少注册号”都不应单独解释为假货；“话术与案例相似”也不表示当前商品或商家就是案例对象。

## 当前技术限制

- 尚未连接可以稳定、合法自动调用的国家官方数据库接口。
- 动态电商页面、登录后内容、评论和短链跳转可能无法读取。
- OCR、正则规则、网页解析和截图比对都有误识别可能，需要用户核对原包装和官方页面。
- 本地案例资料不是实时更新，也不完整覆盖所有消费风险。
- 当前版本尚未完成应用商店发布、生产签名和大规模真实用户测试。

## 发布前仍需完成

- 面向真实部署环境的隐私政策与数据安全说明
- 无障碍审计、老年用户可用性测试和问题修复
- Release 签名、混淆策略、依赖与供应链检查
- 官方来源链接和内置案例的定期复核机制
- 如恢复 AI：用户同意、日志脱敏、速率限制、成本上限与退出机制
