# 银龄安心查 Android MVP 0.2.2

面向老年消费场景的 Android 原生风险初筛 App。

## 0.2.2 商品信息结构化提取

- 从 OCR 或手动输入中整理商品名称、品牌、生产企业、型号、规格/净含量、注册/备案号和价格。
- 结果页逐项展示已识别内容和缺失字段，不再只显示型号与价格。
- 对商品名称提供谨慎的无标签推测，其余关键字段优先依据包装标签提取。
- 提醒用户补拍包装正反面，并明确所有提取内容都需要对照原包装核实。
- 分享给家人的风险报告会同时带上已整理的商品信息。

## 0.2.1 交互优化

- 页面避开状态栏、摄像头区域和底部导航栏。
- 键盘弹出时页面仍可滚动到“开始分析”，分析后自动收起键盘。
- 使用“拍商品查”“选截图查”等更直接的老人友好文案。
- 结果页直接解释“为什么风险高”。
- 官方记录区域明确显示“尚未自动核验”。
- 结果页底部常驻“发给家人一起看看”按钮。

## 这一版和网页 0.1 的区别

- 原生 Android App，不是 WebView。
- Kotlin + Jetpack Compose。
- 直接调用系统相机拍照识别。
- 从系统相册选截图。
- 使用 Google ML Kit 中文 OCR，本地识别商品截图文字。
- 不需要申请相册存储权限。
- 健康、节电、赚钱三类高风险消费话术初筛。
- 自动提取简单的价格和型号。
- 风险分 + 可解释命中原因。
- 按商品类别给出国家药监局、市场监管总局、全国标准信息平台等官方核验入口。
- Android 系统分享，可直接发给微信/短信等家人协同核验。
- 明确区分“风险初筛”和“官方认定”。

## 当前边界

### 已经真实完成
截图 → OCR → 风险识别 → 初步分类 → 价格/型号简单提取 → 官方核验入口 → 分享

### 还没有伪装完成
自动查询国家数据库。

也就是说，本版本不会显示假的：
- “国家认证：通过”
- “该品牌可以买”
- “未备案，所以一定是假货”

```text
 ├─ 市场监管总局
 └─ 国家标准

精确匹配 + 数据来源 + 查询时间
```

## Android Studio 运行

推荐：
- 最新稳定 Android Studio
- JDK 17
- Android SDK 37

步骤（Windows）：
1. 解压项目。
2. 在项目目录打开 PowerShell，执行：
   `powershell -ExecutionPolicy Bypass -File .\bootstrap-wrapper.ps1`
3. Android Studio → Open → 选择本项目文件夹。
4. 等待 Gradle Sync。
5. 准备 Android 6.0（API 23）以上真机或模拟器。
6. Run `app`。

`bootstrap-wrapper.ps1` 只下载 Gradle 官方的 `gradle-wrapper.jar`。之所以单独放这个步骤，是因为当前生成环境不能直接把外部二进制 JAR 打进交付包；项目源码本身已经完整。

首次 Gradle Sync 需要联网下载依赖。
