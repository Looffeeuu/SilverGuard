# 银龄安心查 Android MVP 0.3.0

面向老年消费场景的 Android 原生风险初筛与官方核验辅助 App。

## 0.3.0 官方信息核验 MVP

- 识别医疗器械、药品、保健食品和化妆品的常见注册 / 备案编号格式。
- 根据结构化商品信息判断当前是否具备官方核验条件，并说明缺失字段。
- 按编号类型匹配国家药监局、医疗器械 UDI、市场监管总局和特殊食品信息查询平台等官方入口。
- 统一展示核验状态、官方数据来源和核验时间；本版核验时间始终如实显示“尚未查询”。
- 增加宣传内容与商品登记类型的第一层冲突提示，不直接作出违法、假货或官方认证结论。
- 结果摘要同时展示宣传风险、商品信息完整度和官方核验状态。
- 分享报告升级为商品信息、风险分析、官方核验和购买建议四个部分。
- 将核验业务逻辑与 Compose UI 拆分，并增加可重复运行的单元测试。

## 0.2.2 商品信息结构化提取

- 从 OCR 或手动输入中整理商品名称、品牌、生产企业、型号、规格/净含量、注册/备案号和价格。
- 结果页逐项展示已识别内容和缺失字段，不再只显示型号与价格。
- 对商品名称提供谨慎的无标签推测，其余关键字段优先依据包装标签提取。
- 提醒用户补拍包装正反面，并明确所有提取内容都需要对照原包装核实。
- 分享给家人的风险报告会同时带上已整理的商品信息。

## 0.2.1 交互优化

- 页面避开状态栏、摄像头区域和底部导航栏。
- 键盘弹出时页面仍可滚动到“开始分析”，分析后自动收起键盘。
- 使用“拍商品查”“选截图查”等更直接的老人友好文案。
- 结果页直接解释“为什么风险高”。
- 官方记录区域明确显示“尚未自动核验”。
- 结果页底部常驻“发给家人一起看看”按钮。

## 这一版和网页 0.1 的区别

- 原生 Android App，不是 WebView。
- Kotlin + Jetpack Compose。
- 直接调用系统相机拍照识别。
- 从系统相册选截图。
- 使用 Google ML Kit 中文 OCR，本地识别商品截图文字。
- 不需要申请相册存储权限。
- 健康、节电、赚钱三类高风险消费话术初筛。
- 自动提取商品名称、品牌、生产企业、型号、规格、注册 / 备案号和价格。
- 风险分 + 可解释命中原因。
- 按商品类别给出国家药监局、市场监管总局、全国标准信息平台等官方核验入口。
- Android 系统分享，可直接发给微信/短信等家人协同核验。
- 明确区分“风险初筛”和“官方认定”。

## 当前边界

### 已经真实完成
截图 → OCR → 结构化提取 → 风险识别 → 编号分类 → 核验准备度 → 官方人工查询入口 → 宣传冲突提示 → 分享

### 还没有伪装完成
自动查询国家数据库。

也就是说，本版本不会显示假的：
- “国家认证：通过”
- “该品牌可以买”
- “未备案，所以一定是假货”

如果未来存在稳定、合法且适合 App 调用的官方公开接口，可以继续升级为：

```text
截图
 ↓
OCR
 ↓
品牌 / 产品名 / 型号 / 注册编号结构化抽取
 ↓
官方公开接口或合规数据集
 ├─ 国家药监局
 ├─ 医疗器械 UDI
 ├─ 市场监管总局
 └─ 国家标准
 ↓
精确匹配 + 数据来源 + 查询时间
```

## Android Studio 运行

推荐：
- 最新稳定 Android Studio
- JDK 17
- Android SDK 37

步骤（Windows）：
1. 解压项目。
2. 在项目目录打开 PowerShell，执行：
   `powershell -ExecutionPolicy Bypass -File .\bootstrap-wrapper.ps1`
3. Android Studio → Open → 选择本项目文件夹。
4. 等待 Gradle Sync。
5. 准备 Android 6.0（API 23）以上真机或模拟器。
6. Run `app`。

`bootstrap-wrapper.ps1` 只下载 Gradle 官方的 `gradle-wrapper.jar`。之所以单独放这个步骤，是因为当前生成环境不能直接把外部二进制 JAR 打进交付包；项目源码本身已经完整。

首次 Gradle Sync 需要联网下载依赖。

## 后续推荐目标

只聚焦“老年健康消费”，把可信度做深：

1. 在官方接口稳定、合法并适合移动端调用的前提下接入真实监管数据。
2. 显示：
   - 数据来源
   - 查询时间
   - 匹配字段
   - 匹配置信度
3. 增加“资质存在 ≠ 宣传功效获批”的证据解释。
4. 建立有来源、可追溯的风险案例库。
5. 再做同类价格区间，不先做主观“推荐品牌/骗子品牌”。

## 隐私设计

0.3.0 的截图 OCR、结构化提取、编号分类和风险分析都在设备本地完成。
App 不主动上传用户截图，也没有声明 INTERNET 权限。
点击官方查询按钮时，会交给系统浏览器访问对应官方网站。
